Git for Students: What is it and Why Should You Use it?

March 18, 2026

Git is a version control system created by Linus Torvalds in 2005.

What is version control?

Imagine you're working on an important project. You save files like "final_thesis.doc," then "corrected_final_thesis.doc," and then "final_thesis_definitive.doc." We've all done this at some point.

Version control systems do this automatically, but better. Git saves snapshots (called "commits") of your project with every major change. You can revert to any previous version whenever you want.

Basic commands I learned

During this project, I used the following Git commands most frequently: - **git init** – Initializes a new repository - **git add .** – Adds all files to the staging area - **git commit -m "message"** – Saves changes with a description - **git remote add origin URL"** – Connects my local repository to GitHub - **git push** – Sends changes to GitHub - **git status** – Displays the current status of files - **git log** – Displays the change history

Why is Git so popular?

1. It's free and open source. 2. It works offline (you can make local commits). 3. It's very fast. 4. It allows teamwork without overwriting each other's work. 5. GitHub uses it, as does GitHub Pages.

LIGHTWEIGHT MARKUP LANGUAGES. MARKDOWN

What is Markdown?

Markdown is a lightweight markup language created by John Gruber in 2004. Its main goal is to 
allow formatted text to be written using simple characters, making it easily readable even 
without converting it to HTML.

What is Markdown good for?

Markdown is used in many areas:

- Writing README files on GitHub
- Creating blog posts
- Writing technical documentation
- Quick note-taking
- Creating academic reports

Basic Markdown Commands

Here are the commands I already use in my studies:

| Formatting | Syntax | Example |
|----------------|-----------|--------|
| Heading 1 | # Text | # Introduction |
| Heading 2 | ## Text | ## Methodology |
| Bold text | text | important |
| Italic | *text* | *note* |
| Bulleted list | - text | - first item |
| Numbered list | 1. text | 1. first step |
| Link | [text](url) | [Google](https://google.com) |
| Image | ![alt](url) | ![photo](https://image.jpg) |

My experience using Markdown

As a second-year international student at RUDN University, Markdown has made my studies much 
easier. Previously, I used Word or wrote directly in HTML, which was slow and difficult. Now 
I can:

- Write your reports faster
- Keep your code clean and organized
- Publish content directly to your website via GitHub Pages
- Focus on content, not formatting

Conclusion

Markdown is an indispensable tool for any computer science or programming student. It's easy to 
learn, quick to use, and very user-friendly. I highly recommend it.

Как создать хорошую презентацию: советы для студентов

In this article, I want to share my experience and give some practical tips for creating effective presentations. As a student, I often prepare presentations for various subjects, and during this time, I've learned several important rules.

1.-Choose the right tool

There are many programs for creating presentations. I use:

  • Microsoft Powerpoint-A classic tool with great capabilities.
  • Google Slide - convenient because you can work online and share a link.
  • Canva - great for beautiful designs and templates.

2.-Presentation structure

A good presentation always has a clear structure:

  • Introduction - introduce the topic and say what you'll talk about
  • Body - develop the main ideas, use facts and examples
  • Conclusion - summarize and answer questions

3.-Design and Decoration

Here are a few rules I always use:

  • Use a minimalist template.
  • Choose readable fonts (Arial, Calibri, Times New Roma).
  • Font size: headings - 36-44, text - 24-32.
  • Avoid using too much text on one slide.

4. Working with text

  • Use short sentences
  • Use bulleted lists
  • Don't overload your slides with information (maximum 5-7 bullet points)
  • Add images, graphs, and charts for visualization

5. Practice before the performance

Be sure to practice before your performance. I always:

  • I read the text out loud several times
  • I check the speaking time
  • I use speaker notes (in PowerPoint or Google Slide)
  • I ask a friend to listen to me and give feedback

conclusion

Creating a good presentation is a skill that will be useful not only in your studies but also in your future career. The key is to remember that the presentation should enhance your presentation, not distract from it.

Scientific programming languages: Python, MATLAB, R, and Julia

In this article, I'll talk about scientific programming languages—those used in research, statistics, and data analysis. As a Mathematics and Computer Science student, I've worked with several of them and want to share what I've learned.

What is a scientific programming language?

A scientific programming language is a language designed for working with mathematical formulas and matrix operations. This means they have built-in tools for performing complex calculations more easily than conventional programming languages.

Language comparison

The four most popular languages ​​in science are:

  • PYTHONThe most versatile. Used in data science, machine learning, and web development. Its strength lies in its libraries: NumPy, SciPy, and Matplotlib. It's free and has a huge community.
  • MATHLABVery popular in engineering and applied mathematics. It's known for its fast matrix processing and many specialized tools. It's paid, but universities often offer licenses.
  • RThe favorite language of statisticians. It has thousands of packages for statistical analysis and data visualization. Free, active academic community.
  • JuliaThe youngest language. Designed to be fast and easy to use. Ideal for high-performance computing.Free and open.

Which language should I choose?

There's no single best language—it all depends on the task. If you work with data and statistics, R is an excellent choice. If you need speed and complex simulations, try Julia. For machine learning or development projects, Python is unrivaled. And if you're an engineer or work with matrices, MATLAB remains a very powerful tool.

Conclusion

Knowing multiple languages ​​gives you flexibility. I started my studies with Python, and now I'm learning R and Julia. Each language has its own strengths. And knowing how to choose the right tool for the task is an important part of being a data scientist.
